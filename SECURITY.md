# Security policy

## Reporting a vulnerability

Please report security problems privately. **Do not open a public issue.**

- **Preferred:** use GitHub's [private vulnerability reporting](https://github.com/AllenZheng-05/OpenTeamSheets/security/advisories/new).
- Additionally you can email security@openteamsheets.com.

Include what you found, how to reproduce it, and security flaw it exposes.
